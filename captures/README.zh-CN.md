# 留存射频样本

[English](README.md)

这些 CSV 来自所有者在 2026-10-21 的实际落地灯遥控器采集，不是硬件响应模拟。
[索引](index.json)区分已标定按键、未标定调试数据，以及所选[完整帧](frames/)的准确来源范围。
其中 Phase 2 的重放标志属于当时记录，不表示最新灯具结果。

Git 保留 CSV 字节，以维持生成波形的来源哈希。内置命令是有意公开的灯具控制样本，
不是认证凭据；尚未确定地址字段含义或其他设备兼容性，不作为安全敏感门禁示例。

新的本地采样默认忽略。有意增加测试样本前，应去除个人设备标识及无关通信，
确认有权公开，并保留真实时序及来源索引。不得伪造或悄悄量化采样。
原始串口日志可能含凭据和标识，因此只保留本地。详见[射频指南](../docs/zh-CN/rf-protocol.md)。
