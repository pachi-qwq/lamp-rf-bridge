<!-- section: network -->
## 访问网关

手机需能访问网关所在局域网。ESP32 连接 2.4 GHz Wi-Fi，手机可以使用同一路由器的 5 GHz，
前提是两个网络互通；访客网络或客户端隔离可能阻止访问。仅用蜂窝流量无法直接控制。
连接回家中网络的 VPN 可作为独立部署方案，但不是项目内置的远程控制功能。

使用设备打印的地址；网络支持 mDNS 时也可尝试 `lamp-xxxxxx.local`。
尚未专项验证所有平台的名称解析。IP 改变后需更新入口；路由器 DHCP 地址保留可避免变化。

<!-- section: login -->
## 登录与设备信任

用户名为 `admin`，随机 16 位访问密码由物理 USB 的 `access` 输出取得，也用于配网热点。
它不是通用出厂密码。标准表单使用 username/current-password 自动填充属性，
已在 iPhone 验证密码填充。访问 `/login` 可在已有会话时仍显示登录表单。

“信任此设备”后凭证跨 ESP32 复位保留。设备最多保存四个 SHA-256 凭证哈希；
同一浏览器重新登录会替换旧凭证。Cookie 为 HttpOnly、SameSite=Strict、仅当前 Host，
浏览器 Max-Age 为一年。ESP32 没有可靠实时时钟，不承诺服务器强制一年到期。

不选择信任时使用最多八项的 RAM 会话，有效期八小时，ESP32 重启即失效。
“已信任 · 取消”撤销持久信任并签发新的 RAM 会话，当前窗口仍保持登录，
不是“退出所有设备”。不同地址、浏览器、无痕窗口或清除站点数据后可能需要分别登录。

<!-- section: controls -->
## 操作按键

| 页面标签 | 含义 | 行为 |
| --- | --- | --- |
| 电源图标 | 电源切换 | 切换一次，不是绝对开或关 |
| 调亮 / 调暗 | 亮度增加 / 减少 | 相对调整一步 |
| 偏冷 / 偏暖 | 色温增加 / 减少 | 相对调整一步 |
| 夜灯 | 夜灯模式 | 已采集的预设命令 |
| 10 分钟 | 十分钟定时 | 已采集；效果及到期未实测 |

七个操作均逐次处理，不自动重试、不长按连发。“已发送”表示网关完成波形并确认 IDLE，
不能证明灯已接收。请求超时后，先观察灯再决定是否重按电源。

灯图形动画只是**操作示意**，不是实时状态；原遥控器操作、断电或漏收都可能使它与实灯不一致，
切回页面后恢复中性。状态标签仅表示网关与模块状况，不可据此推断实际亮度或色温。

## 添加 iPhone 主屏幕入口

Safari 打开网关，选择分享 → 添加到主屏幕；若出现“作为网页 App 打开”，保持开启。
在主屏幕入口内部登录并选择信任。Android 可使用浏览器提供的主屏幕快捷方式，
但 Android 安装行为尚未专项审计。

应用使用 SVG 主图标及 iOS PNG 兼容图标。控制页固定高度并禁止滚动，
登录及配网页允许为键盘滚动。仓库提供匹配已测 iPhone 17 Pro 显示模式的 1206×2622 深色启动图。

这是带 standalone 清单的在线 HTTP 局域网应用，没有 Service Worker 或离线命令缓存，
也不依赖 Vue。深色启动图不表示联网或灯具状态。修复服务器空闲预连接阻塞后，
使用者报告主屏幕启动在一秒以内；这是单台设备反馈，不是性能承诺。

<!-- section: maintenance -->
## 断线及固件更新后恢复

保存过 Wi-Fi 时，固件每 15 秒尝试重连；断线持续 60 秒后开放有密码的配网热点。
局域网连接成功三分钟后热点关闭。这些网络事件不会触发发射。

更新页面资源后关闭并重开主屏幕应用以加载新版。普通固件上传保留 NVS；擦除 Flash 不保留。
射频故障会锁定控制不可用，应先诊断接线及供电，再复位。详见[故障排查](troubleshooting.md)。
